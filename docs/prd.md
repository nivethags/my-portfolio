\n## 3. Design Style\n
### 3.1 Color Palette
- Primary color: Deep blue (#2563eb) for headers and key elements
- Secondary color: Purple accent (#8b5cf6) for highlights and interactive elements
- Tertiary color: Teal (#14b8a6) for success states and call-to-action buttons
- Background: Clean white (#ffffff) with light gray sections (#f9fafb) for contrast
- Text: Dark gray (#1f2937) for body text, lighter gray (#6b7280) for secondary text

### 3.2 Visual Elements
- Rounded cards with 12px border radius for content sections
- Subtle shadow effects (04px 6px rgba(0,0,0,0.1)) for depth and hierarchy
- Smooth fade-in animations on scroll for section reveals
- Hover effects on interactive elements with0.3s transition duration
- Clean, modern iconography using outlined style icons

### 3.3 Layout Structure
- Section-based single-page layout with smooth scroll navigation
- Fixed navigation bar with section links\n- Full-width hero section on homepage
- Card-based layout for projects with grid display (responsive: 1 column mobile, 2 columns tablet, 3 columns desktop)
- Two-column layout for skills section with category grouping
- Fully responsive design with mobile-first approach\n- Maximum content width of 1200px centered on large screens

### 3.4 Typography
- Headings: Sans-serif font (Inter or similar), bold weight, clear hierarchy (H1: 48px, H2: 36px, H3: 24px)
- Body text: 16px with 1.6line height for readability
- Consistent spacing between sections (80px) and elements (24px)
\n### 3.5 Theme Options
- Light theme as default with option to toggle dark theme
- Dark theme: Dark background (#1a1a1a), adjusted text colors for contrast, same accent colors with adjusted opacity
